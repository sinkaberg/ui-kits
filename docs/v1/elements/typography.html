01 · Headings

One display face, one scale

Sora carries every heading; Inter carries body. Inside .doc the headings step down one notch so a document doesn't shout. Use one .t-h1 per page, then nest by meaning — never skip for size.

02 · Section furniture

Eyebrow, lead and body

Each section opens with an .t-eyebrow — a numbered, salmon, all-caps kicker — then a heading, then a single .t-lead sentence that states the point. Body text follows.

04 · Pull quote

A line worth stopping on

Use .quote to lift a decision, a principle, or a stakeholder's words out of the flow. It sets the text in the display face with a thin salmon rule.

Live

A reading you never lose is worth more than a dashboard you refresh — buffer first, render later.

05 · Inline objects

Code spans and keyboard keys

Inline <code> marks a token, path or identifier in flowing text. Wrap key presses in <kbd>.

Live

Open docs/adr/0042-store-and-forward.md and press ⌘ K to jump, or Ctrl P on Windows.

Open <code>path/to/file.md</code> and press <kbd>⌘</kbd> <kbd>K</kbd>.

06 · References

Footnotes that link both ways

A reference marker .fnref links to a numbered entry in a .footnotes block; each entry links back. The target row highlights when jumped to.
