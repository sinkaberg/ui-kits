01 · Ordered procedure

Numbered steps

An .steps ordered list auto-numbers each item in a navy disc — for a procedure where order is the point.

Live

  1. Threshold crossed. A reading from «Måkeholmen» breaches its configured limit — oxygen below the floor, or temperature above the ceiling.

  2. Confirm window. «Strømvarsel» waits for the next reading before acting, so a single spike never pages anyone.

  3. Notify on-call. «Vaktlista» resolves who holds the watch and sends the alert.

  4. Log the event. The alert and its readings land in «Bøyeloggen» for the morning review.

03 · Switchable views

Tabs

One region, several panels. Good for showing the same sensor id rendered per surface, or a snippet in several languages. Keyboard-navigable; falls back to stacked panels without JS.

Live

Resolved to a path inside the dashboard's site view:

/sites/maakeholmen/sensors/temp-03

Rewritten to the hub API URL for a client fetching readings:

hub.example/api/v1/readings/maakeholmen/temp-03

Flattened to an in-document anchor in the daily export:

#sensor-maakeholmen-temp-03
<div class="tabs" data-tabs>
  <div class="tabs__list">
    <button class="tabs__tab" data-tab="dash">Dashboard</button>…
  </div>
  <div class="tabs__panel" data-panel="dash"> … </div>…
</div>

06 · Architecture figures

Diagram vocabulary

Hand-authored SVG using the .dg-* classes so every diagram shares the brand's nodes, edges and salmon emphasis. Wrap it in a .card figure with a legend and caption.

Define the two <marker> arrowheads once inside the SVG's <defs>; the edge classes reference them by id.
