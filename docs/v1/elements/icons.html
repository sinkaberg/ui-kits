01 · The set

Thirteen icons, one line weight

All icons share a 100 × 100 viewBox, filled paths (no strokes) and a single colour per file, so they sit evenly at any size. Shown here in the primary variant, blue-deep.

02 · Colour variants

Four colours, one geometry

Every icon exists in four fills, one folder per variant. The geometry is identical — pick the variant by the surface it sits on, never by mood.

03 · Using them

Embed as an image, size with width

Reference the SVG file directly — no sprite sheet, no inlining needed. The square viewBox means width alone keeps the proportions. Always give an alt that names the concept, not the file.

Live · inline with text

<img src="brand/assets/icons/blue-deep/wellboat.svg"
     alt="Wellboat" width="32" height="32">

Don't recolour by hand. The four variants are the palette. If a new colour is ever needed, copy a variant and change the single fill in its <style> block — never edit paths, and never introduce hex values outside the brand tokens.
