03 · Guidance

Do / don't comparison

Two columns, green ticks against red crosses. Use it to turn a principle into concrete practice — the shape reads faster than a paragraph of prose.

Live
✓ Do
  • Buffer readings at the gateway until the hub acknowledges.
  • Address sensors by logical id, never by host.
  • Publish each reading once; let subscribers fan out.
✕ Don't
  • Wire every dashboard to every sensor — that's O(n²) and rots fast.
  • Hard-code a gateway's IP into an alert rule.
  • Drop readings when the uplink blips — forward later instead.
