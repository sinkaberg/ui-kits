01 · Admonitions

Five callouts, one per intent

Each carries a left rule in its semantic colour and a tinted fill. Pick by meaning, not by mood: note for asides, info for context, success for confirmations, warning for open risks, danger for hard stops.

Live · all five

Note. A neutral aside — context that helps but isn't a warning.

Info. Background the reader needs to make sense of the section.

Works alone. Cut the uplink and the gateway keeps logging — buffered readings forward once it returns.

Still open. The hub's retention window and the alert-rule file format are not yet decided.

Do not mutate. An alert rule must never rewrite a reading — it subscribes and flags downstream instead.

<div class="callout callout--warning">
  <p class="t-body-s"><strong>Still open.</strong> …</p>
</div>

02 · Inline labels

Pills, tags and badges

Three weights of inline label. A pill is an outlined descriptor, a tag is an ice-filled category, a badge is a salmon-tinted state marker. All sit inline and share the display face.

Live
One stream · many sites sensor måling varsel you are here new 
<span class="pill">One stream</span>
<span class="tag">sensor</span>
<span class="badge">you are here</span>

On a dark hero, .pill flips to a light outline automatically — no modifier needed.

03 · Document state

Status chips

A .status chip carries a document's lifecycle state with a coloured dot. Use it in the hero meta-row and in the repo index. Four states cover the review flow.
