01 · The basics

Plain code block

A .code block is a bare navy panel — good for a stored address, a shell line, or an ASCII sketch. Inline <code> handles single tokens in prose.

Live
sensor id: maakeholmen/temp-03
           └─────────┘ └─────┘
           site slug    sensor (type + number)
<pre class="code"><code>sensor id: maakeholmen/temp-03</code></pre>

02 · With context

Annotated code — filename & highlights

A titled bar names the file and language; wrap each line in .ln and add .ln--hl to draw the eye to what matters.

Live
maakeholmen/temp-03.md yaml 
---type: sensorid: maakeholmen/temp-03aliases: [MH-T3]site: maakeholmen# registered before the first reading arrives---
<div class="codeblock">
  <div class="codeblock__bar">
    <span class="codeblock__name">path/to/file.md</span>
    <span class="codeblock__lang">yaml</span>
  </div>
  <pre><code><span class="ln">---</span><span class="ln ln--hl">id: …</span>…</code></pre>
</div>

Keep each .ln on one source line with no whitespace between spans — the block preserves newlines, so stray gaps become blank rows.

03 · Changes

Added & removed lines

For a changelog entry or a review, .ln--add and .ln--del tint lines green and red — a lightweight diff without a full syntax pipeline.

Live
stromvarsel/alert-rules.yml diff 
## Varsling- Ring vakta manuelt (gammel rutine)- varsle: vaktlista/maakeholmen- varsle: vaktlista/ternebaaen## Ansvar
<span class="ln ln--del">- old line</span>
<span class="ln ln--add">+ new line</span>
