01 · Text & type

Text & typography

The written layer — the scale, the accents, and the reference apparatus.

Open the gallery →

Type scale

.t-display · .t-h1…h6 · .t-lead · .t-body · .t-caption

One .t-h1 per page, then nest by meaning. Inside .doc headings step down one notch so a document reads calmly. .t-lead is the single setup sentence under a heading.

Eyebrow

.t-eyebrow

The numbered, salmon, all-caps kicker that opens every section. Carries the section number and a short label.

Highlight

.hl

Salmon-colour one phrase in running prose to mark the load-bearing idea. Once or twice a page — it stops working if everything is highlighted.

Pull quote

.quote

Lift a principle, decision or stakeholder line out of the flow, set in the display face with a thin salmon rule and an optional <cite>.

Keyboard key

<kbd>

Wrap a literal key press. Use for shortcuts in guides and runbooks.

Footnotes

.fnref · .footnotes

A superscript marker that links to a numbered entry and back again. Use for citations and asides that would break the sentence.

02 · Signals

Callouts & status

Flag, label and quantify. Colour carries meaning here, so spend it deliberately.

Open the gallery →

Callout

.callout · --note --info --success --warning --danger

Admonitions. Pick by intent: note (aside), info (context), success (it works), warning (open risk), danger (hard stop). Not for decoration.

Pill

.pill

An outlined descriptor for a whole-thing label — «One stream · many sites». Flips to a light outline on a dark hero automatically.

Tag

.tag

Ice-filled category chip. Group several to classify a page — topics, areas, entity kinds.

Badge

.badge

Salmon-tinted state marker — «you are here», «new». The loudest of the three; use once.

Status chip

.status · --draft --proposed --accepted --deprecated

A document's lifecycle state with a coloured dot. Put it in the hero meta-row and in the repo index.

Stat block

.stats · .stat

A row of headline numbers with captions. Reserve for the few figures that carry the argument — four is the ceiling.

03 · Facts side by side

Tables & data

Choose by shape: many rows, one thing's attributes, guidance, or term–definition.

Open the gallery →

Data table

.table

Many rows, several columns, a header. Zebra stripes and an uppercase header. Wrap in overflow-x:auto so it never breaks the measure.

Spec table

.spec · .spec--boxed

Key–value pairs for one thing's attributes — front-matter, entity properties, endpoint params. No header row. --boxed adds a bordered, filled-label frame.

Do / don't

.compare · .compare--do · .compare--dont

Two columns, green ticks vs red crosses. Turns a principle into concrete practice faster than a paragraph.

Definition list

.dl

Compact term–definition pairs inside a section. Collapses to stacked rows on narrow screens.

Glossary

.glossary

Full-row terms with an optional mono «also-known-as» line, for a standalone terminology page.

04 · Machine text

Code & trees

From a single token to an annotated file, plus the repo tree.

Open the gallery →

Inline code

<code>

A token, path or identifier inside prose — maakeholmen/temp-03.

Code block

.code

A bare navy panel for a stored address, a shell line, or an ASCII sketch.

Annotated code

.codeblock · .ln · .ln--hl · .cmt

A titled bar names the file and language; per-line .ln--hl draws the eye to the lines that matter.

Diff lines

.ln--add · .ln--del

Green/red line tints for a changelog or review — a lightweight diff without a syntax pipeline.

Repo tree

.tree · .dir · .file · .anno · .t-mark

Show the layout on disk. Annotate files, and flag the one path you're pointing at with .t-mark.

05 · Sequence & arrangement

Flow & structure

Order, time, switchable views, and the diagram vocabulary.

Open the gallery →

Numbered steps

.steps

An ordered list where order is the point — a procedure. Auto-numbered navy discs.

Pipeline

.pipe · .step

A short left-to-right process on one line, chips joined by salmon chevrons.

Tabs

.tabs [data-tabs]

One region, several panels — the same thing rendered per surface, or a snippet in several languages. Keyboard-navigable; needs sinkaberg-docs.js, degrades to stacked panels without it.

Timeline

.timeline · .is-done · .is-current

A document's history or a project's milestones. Mark nodes done (green) or current (salmon ring).

Cards & grid

.card · .grid · .cols

The salmon-topped container; auto-fit several in a .grid, or split two peers with .cols.

Composite figure

.whole · .layer · .area-grid · .area-box

The nested-boxes diagram for a layered system — a central layer over independent parts. Pure HTML, no SVG.

Diagram vocabulary

.dg-node · .dg-edge · .dg-label · .dg-legend

Hand-authored SVG that inherits the brand's nodes, edges and salmon emphasis. Wrap in a .card figure with a legend and caption.

06 · Brand icons

Icons

The 13 bespoke line icons — the value chain from smolt to salmon factory — each in four brand colours.

Open the gallery →

The set

brand/assets/icons/<variant>/<name>.svg

Plain SVG files, 100 × 100 viewBox, one colour per file. Embed with <img> and a width; no sprite sheet or inlining needed.

Colour variants

blue-deep · blue-bright · salmon · white

blue-deep is the default on light surfaces, white for navy heroes, salmon for the one emphasised icon per view. Never recolour by hand — the four variants are the palette.

08 · House rules

Six things that keep it consistent

  1. Salmon is scarce. It marks one thing per view — the key figure, the current step, the load-bearing phrase. Never a background.

  2. Colour means intent. Callouts and status chips carry semantics; don't pick them for mood.

  3. One display face, one scale. Sora for headings, Inter for body. Nest headings by meaning, never skip for size.

  4. Narrow measure. Section prose caps around 68 characters so lines stay readable.

  5. Tokens only. Reach for var(--sp-5), var(--salmon) — never raw hex or magic pixels in a page.

  6. Degrade gracefully. Every page works with no JS: tabs stack, the TOC still links, print drops the chrome.
