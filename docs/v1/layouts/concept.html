The site gateway, in one picture

Every sensor on a sea site produces its own stream. Instead of each instrument talking to the central hub on its own, they all publish to one local node — the gateway. That single move is what keeps the fleet from tangling.

A single sea site carries many instruments. Temperature logs the water column, oxygen watches saturation, the current meter tracks flow, the camera streams the pens. None of those streams reaches shore on its own. They are peers.

Publish every reading to the local gateway, and the hub stays simple no matter how many instruments a site carries.

The gateway buffers locally — plain store-and-forward — so it works before the shore link does. Cut the site off and it keeps recording; when the link returns, the backlog drains to the hub in order, and a reading delayed is never a reading lost.
