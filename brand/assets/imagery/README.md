# Brand imagery (mirror)

Grainy blue gradients, the locality map, and cold North-Atlantic photography live canonically
in the Claude Design project (`assets/imagery/`) and are mirrored **down** into this folder
via `/design-sync`. These are binary assets (PNG/JPG).

pull to fill this folder before any slice that uses brand imagery. Expected files:
